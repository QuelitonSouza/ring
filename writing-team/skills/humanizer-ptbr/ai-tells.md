# Catálogo de AI Tells (PT-BR)

> Catálogo exaustivo dos sinais que denunciam texto gerado por IA em português.
> Use para DETECTAR. A reescrita está em [rewrite-patterns.md](rewrite-patterns.md).

---

## 1. Léxico Clichê

> Palavras e expressões que a IA superusa em português. Cada uma tem alternativa humana — ou simplesmente sai fora.

| Expressão de IA | Por Que Soa de IA | Alternativa Humana |
|-----------------|-------------------|---------------------|
| **Vale ressaltar / vale lembrar / vale destacar** | Muleta de transição que IA repete | Corte ou diga direto: "Lembre que..." / só afirme |
| **Em suma / em resumo / em síntese** | Fechamento formulaico | "No fim das contas" ou simplesmente conclua |
| **No mundo de hoje / nos dias de hoje** | Abertura genérica e vazia | "Hoje" ou seja específico: "Desde 2020..." |
| **Mergulhe / vamos mergulhar** | Calque de "dive into" | "Vamos ver" / "Bora entender" / "Olha só" |
| **Desbloqueie o potencial** | Marketing de IA puro | "Aproveite melhor" / "Tire mais de" |
| **Eleve / eleve seu jogo** | Calque de "elevate" | "Melhore" / "Dê um passo à frente" |
| **Robusto / solução robusta** | Adjetivo curinga de IA | "Confiável" / "que aguenta o tranco" |
| **Fluido / experiência fluida** | Calque de "seamless" | "Sem travas" / "sem fricção" / "tranquilo" |
| **Perfeito / perfeitamente** | Hipérbole vazia | Corte ou troque por algo concreto |
| **De tirar o fôlego / impressionante** | Entusiasmo artificial | Mostre o porquê em vez de adjetivar |
| **Não é apenas X, é Y** | Construção contrastiva clássica de IA | Afirme só o que importa: "É Y." |
| **Imagine isso / imagine só** | Abertura teatral repetida | Vá direto à cena ou ao fato |
| **No final do dia** | Calque de "at the end of the day" | "No fim das contas" / "afinal" |
| **Game changer / divisor de águas** | Clichê de impacto | Diga o que mudou de fato |
| **Sinergia / alavancar / potencializar** | Corporativês de IA | "Combinar" / "usar" / "aumentar" |
| **Crucial / fundamental / essencial (em excesso)** | Inflação de importância | Use uma vez, com critério |
| **Transformador / revolucionário** | Hipérbole de marketing | Descreva o efeito real |
| **Verdadeiro / um verdadeiro X** | Reforço vazio ("um verdadeiro divisor") | Corte "verdadeiro" |
| **Cativante / envolvente** | Adjetivo curinga de conteúdo | Mostre por que prende |
| **Aprimorar / otimizar (genérico)** | Verbo genérico de IA | "Melhorar" / "ajustar" / seja específico |
| **Navegar por (desafios)** | Calque de "navigate challenges" | "Lidar com" / "enfrentar" / "passar por" |
| **Embarque nessa jornada** | Metáfora de jornada batida | Corte a metáfora; diga o que vem |

## 2. Pontuação

> A IA pontua com um padrão reconhecível. Excesso de travessão é o tell número um.

| Padrão | Por Que Soa de IA | Exemplo de "Cara de IA" → Humano |
|--------|-------------------|-----------------------------------|
| **Travessão em excesso (—)** | IA usa o em-dash o tempo todo para apostos | "A ideia — que é ótima — funciona." → "A ideia funciona, e é ótima." |
| **Travessão como muleta de ritmo** | Substitui vírgula/parêntese sem necessidade | "Ele chegou — finalmente — em casa." → "Ele finalmente chegou em casa." |
| **Reticências dramáticas (...)** | Falsa suspensão em todo parágrafo | "E o resultado... foi surpreendente..." → "O resultado surpreendeu." |
| **Aspas curvas exageradas** | Aspas tipográficas em palavras comuns | Põe "tudo" entre aspas → use só quando for citação/ironia real |
| **Ponto e vírgula frequente** | Pontuação culta usada demais | Quebre em duas frases |
| **Dois-pontos abrindo toda frase** | "A verdade é a seguinte:" repetido | Diga a verdade direto |
| **Parênteses explicativos em série** | Comentário lateral em quase toda frase | Integre a informação na frase |

## 3. Estrutura

> O esqueleto do texto entrega a IA antes mesmo das palavras.

| Padrão | Por Que Soa de IA | Exemplo de "Cara de IA" → Humano |
|--------|-------------------|-----------------------------------|
| **Tricolon / listas de três** | "Rápido, fácil e eficiente" em toda frase | "É simples, claro e direto." → "É simples e direto." |
| **Paralelismo excessivo** | Toda frase com a mesma forma | Quebre o ritmo: alterne tamanho e estrutura |
| **Parágrafos do mesmo tamanho** | Blocos uniformes, robóticos | Misture parágrafos longos com frases curtas soltas |
| **Abertura formulaica** | "No mundo acelerado de hoje, X é mais importante que nunca." | Comece pelo fato ou pela cena |
| **Fechamento formulaico** | "Em conclusão, fica claro que..." | Termine com a ideia, sem anunciar que vai terminar |
| **Frase-resumo no fim de cada parágrafo** | IA fecha tudo com um laço | Deixe a ideia respirar; nem todo parágrafo precisa de moral |
| **"Primeiro... Segundo... Por fim..."** | Enumeração mecânica visível | Use conectivos naturais ou nada |
| **Toda seção começa igual** | Mesmo gancho repetido | Varie o ataque de cada bloco |

## 4. Tom

> O tom da IA oscila entre o entusiasmo de propaganda e o excesso de cautela acadêmica.

| Padrão | Por Que Soa de IA | Exemplo de "Cara de IA" → Humano |
|--------|-------------------|-----------------------------------|
| **Entusiasmo artificial** | Tudo é "incrível", "fantástico" | "Essa dica incrível vai mudar tudo!" → "Essa dica ajuda bastante." |
| **Hedging (cautela vazia)** | "É importante notar que...", "vale lembrar que..." | Corte a muleta e afirme |
| **Meta-comentário** | "Neste artigo, vamos explorar..." | Comece a explorar — sem avisar |
| **"Como você sabe / como mencionado"** | Auto-referência desnecessária | Corte; o leitor já está lendo |
| **Otimismo obrigatório no fim** | "Com dedicação, tudo é possível!" | Termine honesto, sem frase motivacional plugada |
| **Neutralidade excessiva** | Medo de tomar posição | Assuma um ponto de vista quando o texto pede |
| **"Espero que isso ajude!"** | Encerramento de chatbot | Corte; é texto, não conversa de suporte |
| **Generalização cautelosa** | "Muitos especialistas concordam que..." | Cite quem, ou afirme sem o escudo |

## 5. Formatação

> Quando o texto vem com formatação, a IA também tem manias visuais.

| Padrão | Por Que Soa de IA | Exemplo de "Cara de IA" → Humano |
|--------|-------------------|-----------------------------------|
| **Negrito excessivo** | Várias palavras em negrito por parágrafo | Reserve negrito para 1 ideia-chave, se houver |
| **Emoji decorativo** | 🚀✨🔥 espalhados sem função | Remova (a menos que o registro peça e o usuário queira) |
| **Headings genéricos** | "Introdução", "Conclusão", "Benefícios" | Títulos específicos: "Por que o travessão entrega a IA" |
| **Bullet point para tudo** | Lista onde caberia um parágrafo | Use prosa quando a ideia tem fluxo |
| **Numeração com negrito no item** | "**1. Passo um:** faça X" | "1. Faça X" — sem dobrar a ênfase |
| **Caixa-alta para "atenção"** | "**IMPORTANTE:**" em todo bloco | Deixe a frase carregar a importância |
| **Tabela onde cabia uma frase** | Estrutura demais para pouco conteúdo | Escreva direto |

## 6. Tradução Literal do Inglês (Calques)

> Estruturas que denunciam tradução automática do inglês — o tell mais difícil de perceber.

| Calque (do inglês) | Por Que Soa de IA | Português Natural |
|--------------------|-------------------|--------------------|
| **"Fazer sentido"** (make sense) | Usado para "ter lógica" | "Ter lógica" / "fazer sentido" só quando couber |
| **"No final do dia"** (at the end of the day) | Tradução crua | "No fim das contas" / "afinal" |
| **"Tomar uma decisão"** (make a decision) | Verbo pesado calcado | "Decidir" |
| **"Dar uma olhada"** (take a look) | Aceitável, mas superusado | "Olhar" / "ver" / "conferir" |
| **"Em termos de"** (in terms of) | Conectivo importado | "Sobre" / "quanto a" / reformule |
| **"Não apenas... mas também"** (not only... but also) | Estrutura inglesa rígida | "Além de X, também Y" ou só afirme |
| **"Garantir que"** (ensure that) | Burocrático calcado | "Fazer com que" / "cuidar para" |
| **"Por outro lado"** (on the other hand) repetido | Conectivo de contraste em excesso | "Já" / "mas" / "por outro ângulo" |
| **"Uma vez que"** (once / since) em excesso | Conjunção culta superusada | "Como" / "porque" / "assim que" |
| **"Acionável" / "insights acionáveis"** (actionable) | Anglicismo corporativo | "Que dá para aplicar" / "prático" |
| **"Entregar valor"** (deliver value) | Corporativês importado | "Ajudar de verdade" / "ser útil" |
| **"Construir" (relacionamento, confiança)** (build) | Calque genérico | "Criar" / "ganhar" / "estabelecer" |
| **"Suportar" (suportar idiomas)** (support) | Falso amigo técnico | "Ter suporte a" / "funcionar com" |
| **"Endereçar" (um problema)** (address) | Anglicismo | "Resolver" / "tratar" / "lidar com" |
| **"Aplicação" (de celular)** (application) | Formal demais quando é "app" | "App" / "aplicativo" |
| **"Adicionalmente"** (additionally) | Advérbio de transição importado | "Além disso" / "e ainda" |
| **"Notavelmente / particularmente"** (notably) | Advérbio de ênfase calcado | "Principalmente" / corte |

---

> **Lembre-se:** Nenhum tell isolado condena o texto — é o ACÚMULO que cria a "cara de IA".
> Detecte por categoria, conte os sinais e ataque os mais densos primeiro.
